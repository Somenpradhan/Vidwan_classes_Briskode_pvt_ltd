## 🌟 About the Project

This web application serves as the official digital portal for **Vidwan Classes (Briskode Pvt Ltd)**, a competitive examination coaching institute located in Bhubaneswar, Odisha[cite: 2].

The portal is designed to provide high-conversion course exploration, scholarship exam registrations (**Vidwan Talent Search Test - VST 2026**), topper result analytics, and direct counseling request flows[cite: 2].

## 🚀 Key Features

* **⚡ Responsive Hero Carousel & Marquee:** Animated banner displays highlighting competitive JEE/NEET results and VST registration callouts[cite: 2].
* **📚 Interactive Course Explorer:** Filterable view of 2-Year Integrated (Nurture), 1-Year Intensive (Qualifier), Foundation, and Digi-Connect distance programs[cite: 2].
* **📩 Direct Lead Generation Form:** Integrated quick enquiry modal/form connected to administrative response notifications[cite: 1, 2].
* **📝 Online VST Scholarship Portal:** Dedicated workflow for students in grades 6th–12th to register for up to **90% scholarships**[cite: 2].
* **🖥️ Digi-Connect Smart CBT Hub:** Information panel detailing live interactive HD classes, CBT practice suites, and digital notes[cite: 2].
